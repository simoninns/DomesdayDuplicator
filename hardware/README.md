# Domesday Duplicator Hardware

> **Please note:** The primary repository is [simoninns/DomesdayDuplicator](https://github.com/simoninns/DomesdayDuplicator) which includes this as a submodule.

This directory contains the hardware design files for the Domesday Duplicator PCB.

## Components

### KiCAD
Complete KiCAD project files including:
- Schematic designs
- PCB layout
- Bill of Materials (BOM)
- Gerber files for fabrication

### Documentation
Hardware documentation including:
- Assembly instructions
- Component specifications
- Testing procedures

## Design

The Domesday Duplicator hardware is based on:
- Terasic DE0-NANO FPGA development board
- Cypress FX3 USB 3.0 controller
- High-speed ADC for RF signal capture
- Custom analog front-end circuitry

## Manufacturing

The hardware design files are provided for custom fabrication. Gerber files and BOM are available in the KiCAD directory.
